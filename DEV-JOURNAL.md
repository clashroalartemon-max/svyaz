## Решения

- Ключи чинятся автоматически: битые пары от ранней версии пересоздаются один раз
  (`svyaz.keysRev`). Сообщения, зашифрованные на потерянный ключ, невосстановимы —
  это свойство E2EE, а не баг.
- Публичный ключ автора для `wrappedSelfKey` берётся из приватного JWK (x/y), поэтому
  свои сообщения читаются даже при устаревшем `publicKeyJwk` в профиле.
- Web Crypto требует secure context: по `http://<IP>` шифрование недоступно, поэтому
  в приложении есть предупреждение, а в README — обходные пути (флаг Chrome / HTTPS).
- Node на машине портативный: `%LOCALAPPDATA%\Programs\nodejs`, в PATH не добавлен.
- Пароли вынесены из `profiles` в `credentials`, потому что RLS не умеет скрывать
  отдельные колонки: иначе любой SELECT профилей отдавал бы хэши.
- Realtime — broadcast: `postgres_changes` не увидел бы строки под RLS без
  `x-user-id` в контексте websocket.
