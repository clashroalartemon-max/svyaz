# Отчёт: компактный интерфейс и новые функции

Дата: 2026-11-14. База снова читается (permission denied больше нет),
сборка — 0 ошибок, тесты — 66/66. Проверено в браузере: 390px и 1920px.

## 1. Интерфейс

- **Нижняя панель** — 50px, 4 вкладки: «Чаты», «Создать», «Оповещения»,
  «Ещё». «Создать» открывает модалку нового чата; «Ещё» — шторка с
  «Контакты», «Настройки», «Структура», «Архив». Проверено: панель 50px,
  шторка открывается, архив выбирается. Панель привязана к брейкпоинту
  900px, поэтому видна и в узком окне 390px (раньше пропадала на 768–899).
- **Архив скрыт.** Основные вкладки — «Все», «Группы», «Личные»; стрелка
  «Ещё папки» разворачивает «Взвод», «Командиры», «Курсовые», «Преподаватели»,
  «Архив». Проверено: в свёрнутом виде архива нет, после стрелки — есть.
- **ПК-версия**: список 340px, чат занимает 1580px из 1920 (flex-1), бейджи
  непрочитанных и время на месте, без выбранного чата — «Выберите чат».
- **Мобильная шапка**: имя/группа, настройки, «+»; ничего лишнего.

## 2. Функции

Уже работают (реализовано в предыдущих итерациях, проверялось в браузере):

- чаты: папки, архив, поиск, непрочитанные, ответы, редактирование,
  удаление у себя/у всех, пересылка (текст, медиа, опросы и задачи — без служебных маркеров), закрепление сообщений;
- медиа: голосовые с волной, кружки, фото/видео, документы до 50 МБ,
  стикеры, опросы, @упоминания, «кто прочитал»;
- звонки: аудио/видео P2P с экраном вызова, mute/камера/завершение;
- статусы: онлайн-точка, «печатает…», статус и био, аватар 256×256;
- уведомления: браузерные, звук, упоминания, инкогнито;
- админка: пользователи, CSV, оповещения, журнал, жалобы, бэкап JSON;
- UX: скелетоны, плавная тема, длинный текст, быстрые ответы.

Добавлено в этом раунде:

- разметка сообщений: `**жирный**`, `*курсив*`, `__подчёркнутый__`,
  `~~зачёркнутый~~`, `||спойлер||`, `` `код` `` (тесты `formatting.test.ts`);
- реакции на сообщения: 6 эмодзи в меню действия, хранятся на устройстве
  (тест `reactions.test.ts`; для общих реакций нужна таблица БД);
- панель эмодзи: 24 эмодзи вставляются в текст сообщения;
- геолокация: координаты + ссылка на OpenStreetMap;
- список задач (to-do) с локальными отметками;
- скорость голосовых 1× / 1.5× / 2×;
- компактная навигация, скрытый архив, сворачиваемые папки;
- пересылка сообщения в другой чат с сохранением автора
  («Переслано от …», ForwardModal.tsx): текст, опросы и задачи — читаемой строкой (messageSummary.ts), медиа копируется как файл; в списке чатов вместо [poll]/[todo] — «Голосование»/«Список задач» (превью проверено в браузере);
- скачивание видео из ленты кнопкой у плеера (фото — «Сохранить» в полном
  просмотре);
- фильтр поиска «Файлы»: в панели поиска показывает только медиа и документы
  (проверено: кнопка `aria-pressed`, лента фильтруется).

**Про 1000 функций:** столько не реализовано и не может быть честно
реализовано за один проход. Отложены, в частности: групповые звонки,
демонстрация экрана, запись, шумоподавление, GIF, отправка
контакта, перевод, транскрипция, QR-профиля, 2FA, блокировки, восстановление
из бэкапа, мониторинг ошибок, экспорт чата в PDF. Это отдельные таблицы,
внешние API и миграции; текущий список — roadmap, а не выполненный объём.

## 3. SQL

Если `permission denied for table profiles` вернётся — выполнить
`supabase/fix_permissions.sql` (гранты + колоночные права `status/bio`,
закрытые `credentials`/`auth_tokens`, бакет `avatars`). Сейчас база читается,
значит гранты применены. Проверка аватара: Storage → `avatars` (Public),
загрузка в Настройках создаёт `<user-id>.jpg`.
